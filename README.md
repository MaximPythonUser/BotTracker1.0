  Training Tracker Bot — Telegram-бот для учёта разовых тренировок

Telegram-бот на Python для удобного планирования и отслеживания индивидуальных тренировок. Позволяет пользователям добавлять, просматривать и удалять тренировки с валидацией формата даты и времени.

## Функционал:
✅ Добавление тренировки: /add ГГГГ-ММ-ДД Название ЧЧ:ММ
✅ Просмотр списка тренировок: /my_trainings (с нумерацией для удобства удаления)
✅ Удаление тренировки по порядковому номеру: /delete <номер>
✅ Приветственное сообщение с инструкцией: /start
✅ Валидация входных данных (дата, время, формат команды)
✅ Автоматическое создание и инициализация SQLite-базы данных при старте.

## Стек технологий:
 Python 3.10+
 aiogram 3.x — асинхронный фреймворк для Telegram API.
 aiosqlite — асинхронная работа с базой данных SQLite.
 python-dotenv — безопасное хранение токена бота в переменных окружения.
 datetime — валидация и парсинг даты/времени.

## Особенности реализации:
 1.Асинхронная архитектура: все операции с БД и API Telegram выполняются асинхронно (async/await).
 2.Изоляция данных: тренировки разных пользователей хранятся раздельно по user_id.
 3.Безопасность ввода: защита от некорректных форматов даты и времени через обработку исключений ValueError.
 4.Чистота кода: использование параметризированных запросов (?) для защиты от SQL-инъекций.
